# Diabetic Retinopathy SOP

A standard operating procedure for building an AI system that grades diabetic retinopathy from fundus images.

## Why this exists
Planning document for a fundus-image classification project: it defines the data, labels and evaluation before any model is built.

## What it does
The SOP covers:
- Purpose and scope of the system
- Dataset: 400 PNG fundus photographs, patients aged 35-65
- Diabetic retinopathy severity labels
- Steps for image preparation, metadata, model development, training, evaluation and validation
